At 50% the two disagree: 0.00333 vs a no-action cost of 0 (summary section 8). Fix: use the same window in posterior_predict (or relabel and report both), and regenerate metrics.json and section 7.
2. summary.md section 7 "RUL median [min]" (145.8 / 97.2 / 48.6 min) with censored share 97.7 / 99.7 / 99.3 %. src/uq_calibration.py:75 sets rul_min to the remaining session length when no exceedance occurs, so the median is the session end, not an RUL estimate. Fix: headline P(exceed before session end) and the RUL distribution over exceeding samples only, or drop the RUL claim.
3. metrics.json calibration.coverage95_heldout = 0.9796 and summary "cov95 = 1" at 25/50 %. src/uq_calibration.py:68 adds sig_pm = 7.07 degC of noise to every posterior sample (main.py:282), so the band (about +/-15-20 degC, fig7) is wide enough to make coverage trivial. fig7 also shows the posterior median 5-10 degC above measured pm after each stage, a bias that is not reported. Fix: report the posterior-only band width and mean pm bias, add a naive prior-predictive baseline, and state that coverage here is width-driven.
4. metrics.json surrogate.coverage_2sigma = 0.5157 (nominal 0.95; fig4 title). src/surrogate_model.py:86 combines score variances independently and ignores cross-covariance, and src/surrogate_model.py:103 reports the result. The GP sigma_GP in the likelihood (src/uq_calibration.py:44) is therefore too small. The summary reports the number with no failure statement, although the brief requires the +/-2 sigma check. Fix: calibrate the GP variance (for example, a residual-based noise term or conformal scaling) or report the failure explicitly.
5. Calibration likelihood, src/uq_calibration.py:44 with main.py:281 (sig_obs = free-run RMS, 4.3 / 3.0 / 2.8 degC). Observations are treated as independent every 60 s, but free-run residuals are strongly autocorrelated model error. Posterior-to-prior ratios of 0.10-0.21 (k_cu, C_W, G_WT, G_YC) are therefore overconfident. The limitations text also contradicts itself: sigma_obs is said to include model error, yet "model error ... not included in the posterior". Fix: inflate sigma_obs using the residual autocorrelation (for example AR(1) or effective sample size) and align the limitations text.
6. metrics.json calibration.mean_autocorr_time = 51.27 with 1000 post-burn steps (main.py:291). N/tau is about 19.5, below the emcee guideline of 50. Only the mean tau is reported, and the chains are not converged by that criterion. Fix: run at least 50 x tau per parameter (for example 3000+ steps, which is affordable since the GP takes 2e-4 s per run), and report per-parameter tau.
7. Decision layer, src/decision.py:14-18 and metrics.json decision (optimal_value 1.0, expected_cost 0.0). The optimum is no derating at every stage and every C_thr. Action costs 5 per 30 min, so it only pays when P(exceed) > 0.5 %, and the held-out session never reaches that in its 30-min window. The layer is therefore never exercised, and the headline is trivially zero. Fix: add a stressed scenario (for example a threshold closer to the observed pm range, or a session near 100 degC; the dataset max is 113.6) and report the cost of each policy, not only the argmin.
8. Brief section C asks for identifiability and parameter correlations; neither is reported (no correlation matrix, no identifiability analysis). The hybrid model (11.83 degC) is worse than physics (10.31) and worse than data-driven (6.19), yet summary.md section 4 does not state or discuss that. Fix: add a posterior correlation matrix and a short paragraph on the hybrid failure in summary.md.
